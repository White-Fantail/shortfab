# ShortFab 스타일 갤러리 UX — AG3 / AG4 1차 구현

- 결정: 2026-10-22 (사용자 지시: 자동 배치 대신 다양한 화면/자막 스타일의 슬라이드형 미리보기 카드에서 직접 선택)
- 구현 브랜치: `dev`. 기본 출력 유지: 9:16 MP4/FFmpeg, YouTube source cache.
- 기준: [ROADMAP](ROADMAP.md) · [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md) · [UX](UX_WORKFLOWS.md)

## 사용 흐름

1. YouTube URL 입력, AG2 추천 또는 직접 클립 추가 후 **03 화면**으로 이동.
2. 여러 화면 스타일 카드를 가로로 스와이프/화살표로 넘기고 탭해 선택. 동일 원본 썸네일을 스타일별 구도로 보여준다.
3. **선택 클립의 실제 프레임으로 비교**를 누르면 로컬 FFmpeg가 선택한 클립의 시작 부근 실제 정지 프레임을 꺼내 갤러리 전체에 적용한다. 취소, 오류, 썸네일 대체를 지원한다. 진짜 영상을 가져오기 위해 최초 한 번 다운로드할 수 있다.
4. 구도를 조금 옮겨야 하면 **가로 중심 0~100%** 슬라이더로 조절. 해상도 720p/1080p 고른 후 승인.
5. **04 자막**도 기본 4종 스타일 카드를 스와이프하며 선택. Whisper 생성/수동으로 입력된 자막 cue 내용·시간을 유지한다.
6. 기존 승인/자막/고급 편집/MP4 출력은 그대로 유지. 다른 클립은 별도의 스타일을 저장한다.

## 지금 실제 적용되는 화면 스타일

| ID | 카드 이름 | 실제 FFmpeg 동작 | 미세 조정 |
|---|---|---|---|
| `center` | 중앙 집중 | 9:16 가득 채우고 세로 크롭 | 위치(0~100%) |
| `focus-left` | 왼쪽 강조 | 가로 왼쪽 기준 세로 크롭 | 위치 |
| `focus-right` | 오른쪽 강조 | 가로 오른쪽 기준 세로 크롭 | 위치 |
| `blur-fill` | 전체 화면 | 배경 확대/블러 + 원본 전체 포함(블랙바 최소) | 없음 |

초점 0은 왼쪽, 50은 중앙, 100은 오른쪽 기준이다. 레이아웃 이름은 프리셋 시작점이며 **얼굴·인물 인식이나 동적 트래킹 결과가 아니다.**

자막 스타일은 `classic`, `bold`, `minimal`, `boxed`의 기존 FFmpeg/libass 번인 프리셋을 재활용한다. 카드는 실제 선택 클립 cue 첫 문장이 있으면 그 문장을 예시로 보여주고 없으면 임시 문구를 표시한다. 임시 예시 문구는 **MP4에 삽입되지 않는다**.

## 미리보기의 정확도

- 초기 카드 배경: `i.ytimg.com` 원본 YouTube 썸네일로 만든 **참고 구도 시안**. 선택 구간의 실제 프레임과 시각/인물이 다를 수 있다.
- 사용자 요청 후 카드 배경: FFmpeg가 해당 클립에서 추출한 **실제 정지 프레임** (640px 이하 JPEG, 900 KB 출력 제한). 카드 레이아웃 CSS로 크롭/배경을 근사한다.
- **실제 MP4 렌더:** `src/shared/layout-styles.ts` 필터에서 만들어진 FFmpeg 중앙/좌/우 위치 크롭 또는 블러 배경 합성, 자막 ASS 포함.
- **미구현:** 프레임별 재생되는 렌더 일치 실시간 미리보기와 사람/화자 자동 인식 및 동적 분할. 원본 YouTube IFrame은 출력 합성 플레이어가 아니다. 따라서 카드만 보고 A/V 정확도가 검증됐다고 주장하지 않는다.

## 보안·저장·게시

- 프리셋은 선언형 고정 ID이며 사용자 문자열을 FFmpeg 필터 표현식에 직접 전달하지 않는다. `validateLayout`는 0~100 범위 finite 값을 검사.
- 클립의 `layout` JSON 설정은 프로젝트 저장/재열기와 자동 저장을 거친다. 옛 프로젝트의 누락 필드는 중앙 크롭/50%로 마이그레이션한다.
- 선택 클립의 화면 배치가 달라지면 layout/review/export 단계가 다시 검토 상태로 돌아간다. 선택된 다른 클립의 상태는 유지.
- Export 시 스타일 서명을 같이 기록한다. 편집 후 오래된 MP4는 Electron privileged YouTube 업로드 단계에서 반드시 거절한다.
- FFmpeg 프레임 추출은 Electron main의 정해진 클립 ID·구간에 대해서만 실행, 프로젝트·소스 경로는 renderer에 노출하지 않는다. 미디어 준비와 렌더의 작업 충돌을 직렬화하고 사용자 취소를 지원한다.

## 자동/사용자 테스트 구분

```bash
npm run check
npm run lint
npm test
npm run build
```

자동 검증 파일: `src/shared/layout-styles.test.ts`(기본값/검증/필터/선택 클립별 상태) · `electron/layout-render.test.ts`(합성 원본/실제 JPEG/FFmpeg crop + blur + 자막 포함 MP4). 정적 자막 프리셋의 기존 테스트는 계속 실행된다.

**사용자 수용 대기:** 실제 YouTube/로컬 1~2개 소스에서 4종 레이아웃의 화면 구도, 좌우 초점 슬라이더, 블러 영상·한영 자막·음성, macOS/Windows 재열기 및 MP4 결과를 확인. AG1/AG2 실영상 검증도 아직 시행되지 않았으므로 AG3만 단독으로 최종 완료 처리하지 않는다.

## 이후의 Style Catalog 진화

Trend Studio로 최신 편집 트렌드가 늘어나도 사용자가 이미 승인한 스타일을 덮어쓰지 않는다. 고정된 styleId + semantic version, 안전한 렌더 템플릿, 스타일 카드 예시, 실제 렌더 회귀 테스트, 카탈로그 서명 및 롤백을 도입한다. AG4의 자막 강조/Hook, AG5의 나레이션/BGM, AG6의 CTA에도 **선택형 카드 + 미세 수정** 패턴을 확장한다. 모델 추천은 카드 우선순위 보조 기능일 뿐 기본 자동 확정은 하지 않는다.
