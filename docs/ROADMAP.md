## P0 선행 게이트 — YouTube-first 실제 클립 만들기 (2026-10-22 최우선 추가)

> **핵심 제품 목표:** 사용자는 원본 영상을 직접 촬영하거나 보유하지 않는다. YouTube URL로 기존 영상 구간을 고르고, 필요한 권리 및 인코딩 가능한 원본이 확보된 경우 숏폼 MP4를 제작해야 한다. 로컬 파일 기반 Phase 0/1 성공 및 YouTube **업로드** Phase 2 진행은 이 게이트의 완료를 의미하지 않는다.

- [ ] **YF-0 전체 수용**: URL 기본 소스·IFrame 시각/seek/IN·OUT/루프/후보·재열기. **영상 탐색·클립 선택 후 실제 MP4 출력은 사용자 확인 완료**; 구간 루프·여러 영상·재실행/재열기·제한 영상 경계 사례의 전체 수용은 미완료. 개인용 경로는 위 P0에 별도 기록
- [ ] **YF-1**: YouTubeReference / RightsGrant / MediaBinding / SourceResolver 계약·상태 및 승인된 클라우드/권리자 파일 연결, 싱크 검증 — **로컬 승인 원본 + allowlist HTTPS 직접 미디어 파일 어댑터 구현**. 다운로드 SHA-256/호스트·크기·시간 제한 코드 포함. 실제 승인 클라우드·OS 통합/콘텐츠 동일성/실영상 3개 MP4 검증 미완료
- [ ] **YF-1 Exit**: 사용자가 촬영하지 않은 YouTube 시험 영상의 URL로 시작해서, 재편집/게시 권한과 별도 제공된 적법한 원본을 자동 매핑하여 **클립 3개를 MP4로 익스포트**하고 재열기
- [ ] **YF-2**: 사용자 수동 파일 선택을 줄일 파트너·권리자 제공 원본 자동 연동 및 권한 만료/삭제/동기화 실패 UX — **Ed25519 서명된 videoId→원본 카탈로그 조회 및 자동 바인딩 코드 구현**. 실제 파트너 인증·원본 일치 실증·권한 실시간 철회/키 회전 미구현
- [ ] **YF-3 (조건부)**: 공식 YouTube Clips/Remix 공유 UX. 비공식 추출기 경로는 별도 법률/YouTube 정책·서면 승인 평가 및 ADR 후 결정
- [ ] **사업/출시 게이트**: "임의의 YouTube 공개 링크만으로 항상 MP4 변환" 불가 가능성을 사용자에게 명시하고, 적법한 소스 확보 성공률을 실제 시험 데이터로 측정

**현재 상태: 개인용 공개 YouTube 링크→실제 MP4 한 건 이상 사용자 성공 확인.** YF-0 일부 실기 확인, YF-1 승인 파일·HTTPS 연결 및 YF-2 서명 파트너 자동 탐색은 **코드/자동 테스트 구현** 단계. 실제 파트너 연동·서로 다른 실영상 3개 MP4·게시·배포용 패키징 수용은 미완료. 정확한 구현·수용 기준은 [YouTube-first 설계](YOUTUBE_FIRST_WORKFLOW.md)와 [ADR-0002](adr/0002-youtube-first-source-acquisition.md)를 참조.

### YouTube-first YF-0 구현 기록 (2026-10-22)

- YouTube 영상 URL을 기본 소스로 노출합니다. 공식 IFrame API로 영상 길이/현재 시각을 읽고 구간 seek/IN/OUT 마커, 재생/반복, 타임라인 탐색을 제공합니다.
- YouTube 클립(`source: 'youtube'`)은 로컬 원본 없이 프로젝트 JSON에 YouTube 길이와 함께 저장·재열기 가능합니다. 기존 로컬 클립은 `source: 'local'`로 호환 마이그레이션합니다.
- YouTube 클립이 실제 파일 연결 없이도 프로젝트에서 독립 저장되며, **개인용 직접 출력 경로**에서는 yt-dlp가 먼저 공개 미디어를 가져와 FFmpeg로 변환합니다. 승인된 별도 원본을 사용하는 YF-1 경로는 독립적으로 유지합니다.
- **수용 구분:** 실제 앱에서 YouTube URL→클립→MP4 익스포트 성공은 사용자 확인 완료. 다만 모든 임베딩 정책/지역/로그인 제한, 앱 재실행·구간 반복·URL 변경/저장 경합, 실제 여러 클립 출력은 추가 검증이 필요합니다.

### YouTube-first YF-1 로컬 원본 연결 기록 (2026-10-22)

- `src/shared/sources.ts`: YouTubeReference / RightsGrant / MediaBinding / SourceResolver와 권한/만료/타임 매핑 검증 계약. `electron/sources.ts`: 권리자 파일 해시·FFprobe 검증 및 videoId 로컬 등록 카탈로그.
- 프로젝트에 실제 파일 경로를 비공개 보관하며 클립 탐색 시각을 원본 시각으로 매핑합니다. 권리 만료·SHA 변경·소스 분실을 차단하고 YouTube 게시 허가를 별도 확인합니다.
- GUI: 권리자·증빙 참조·권리 체크박스·만료일·오프셋·SHA-256 및 원본 파일 선택. 연결 후 같은 videoId를 새 프로젝트에서 자동 재매칭합니다.
- **실영상 내용 동일성/법적 허가 진위는 체크섬만으로 증명할 수 없습니다.** 원격 승인 클라우드 원본 공급자와 실영상 3개 MP4 종단 간 검증은 미완료. [YF-1 상세/검증표](YF1_AUTHORIZED_SOURCES.md).

### YouTube-first YF-1 승인 HTTPS 원본 연결 (2026-10-22)

- `SHORTFAB_APPROVED_SOURCE_HOSTS`를 통한 정확한 호스트 allowlist에 한해 직접 다운로드할 수 있는 HTTPS 미디어 URL을 지원합니다. YouTube 영상 URL 자체를 다운로드하지 않습니다.
- 권리자 제공 SHA-256이 필수이며, HTTPS TLS 검사·공개 IPv4 DNS 고정·리다이렉트 거부·120초 타임아웃·최대 2 GiB·응답 파일 포맷·해시 검사를 거쳐 사용자 데이터 디렉터리에 미디어를 보관합니다.
- 다운로드된 파일은 기존 `AuthorizedSources`/프로젝트 `MediaBinding`으로 연결되어 영상 구간·권리 만료·해시 검증 및 MP4 익스포트 절차를 재사용합니다.
- **미완료:** 실제 제휴 저장소의 인증·URL 갱신, 파트너 매니페스트 서명, videoId↔영상 내용 동일성, 클라우드 E2E 시험, 3개 MP4 실제 출력. 설정된 외부 호스트/시험 권리자 미디어가 없으면 직접 증명할 수 없습니다.

### YF-2 파트너 자동 탐색 구현 기록 (2026-10-22)

- `electron/partner-contract.ts`의 Ed25519 서명된 `videoId`·원본 SHA-256·권한·유효기간·다운로드 호스트 검증 계약 및 단위 테스트.

- **코드 구현, 실제 파트너 카탈로그·서명키/권리자 영상·원본 내용 일치·실영상 3개 MP4·OS 검증 미완료.** [프로토콜/수용표](PARTNER_CATALOG.md). YF-2 전체 완료 아님.
