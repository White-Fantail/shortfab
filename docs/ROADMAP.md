### Phase 1 첫 구현 기록 (2026-10-22)

- 프로젝트는 Electron 사용자 데이터 폴더 `projects/{uuid}.json`에 저장하며 파일 경로는 메인 프로세스에서만 관리합니다.
- UI는 자동 저장, 프로젝트 선택/신규 생성, 다중 후보 편집, 원본 누락 시 파일 크기·영상 규격 검사 후 재연결을 지원하도록 코드를 작성했습니다.
- **미검증:** 새 프로젝트 IPC·자동 저장 충돌·재열기·연결 재검증·파일 시스템 오류·빌드/CI. 코드를 작성한 것과 테스트 통과는 별개입니다.
- **다음:** 로컬/CI 타입체크 및 데스크톱 스모크 → 선언형 스타일 기초 → 자막 편집 → 오디오/TTS → CTA 출력.

## 공통 출시 게이트

- 원본이 없을 때 URL 탐색을 렌더 가능으로 오인시키지 않음.
- 스타일 원격 수정/철회가 사용자 콘텐츠를 동의 없이 변경하지 않음.
- 한글·영어 자막이 플랫폼 UI/화면 바깥에 잘리지 않음.
- CTA 오버레이와 엔드카드의 시간 계산 및 음성 믹스 일치.
- 네트워크/AI 오류에도 핵심 로컬 프로젝트 편집·익스포트 경로 유지.
- 게시 승인 없이는 외부 업로드가 시작되지 않고 중복 게시 없음.
- 모든 기능 변경은 README·관련 문서·테스트/구현 상태 반영.
