# ShortFab 개발 로드맵 v2.0 — AI Guided Creation

결정일 2026-10-22. **새 개발의 단일 우선순위 기준.** 종전 Phase 3로 미뤄졌던 AI 클립 추천·스마트 배치를 핵심 P0으로 승격한다. 기존 Phase 0~2 기술 성과는 삭제하지 않고 [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md)에 보존한다.

## 기반 현황 · AG1 + AG2 코드 반영

- **실기 확인:** YouTube URL→수동 클립 선택→실제 MP4 출력 성공(2026-10-22, 1건 이상). 핵심 프로젝트 저장/클립 선택도 사용자 확인.
- **코드/테스트:** Electron, IFrame, yt-dlp 개인용 캐시/FFmpeg, 기본 4종 자막·Whisper STT 연결, YF-1/2 허가 원본/파트너 어댑터, YouTube OAuth 업로드 파이프라인.
- **미검증:** 실제 3클립 연속/QC·캐시, Whisper 실제 한영 모델, Mac/Windows 설치 패키징, 실계정 업로드 및 권리.
- **AG1 코드 반영:** 8단계 진행 UI·URL/클립 수동 대안·클립별 승인 상태 JSON 저장, 유효성 검사 및 Advanced Edit. 실제 대사 기반 자동 클립 후보 생성·재추천은 AG2 코드로 추가됨. 자동 장면/인물 기반 배치, 원격 LLM 추천, TTS/음악/CTA, 합성 프리뷰는 여전히 **미구현**. 기존 동작을 새 기능으로 완료 처리 금지.

### AG2 코드/기능 현황 (2026-10-22)

- `electron/analyze.ts`: 개인 원본 캐시를 공유하는 오디오 분석 작업, 9분 청크 전사, 첫 60분 상한, 취소, 언어·GGML 모델 버전별 JSON 원자 저장·재사용·명시적 재분석. 저장소 경로는 renderer에 노출하지 않음.
- `electron/stt.ts`: 자막 최대 30cue 제한과 별개의 SRT 원본 추출 메서드. `src/shared/recommendations.ts`: 정해진 시간 범위·겹침 검사, 문장 경계·대사 밀도·후킹 표현의 **로컬 휴리스틱**; 학습 모델의 객관적 인기/성공 예측이 아님.
- `src/App.tsx`/`src/WizardPanel.tsx`: 추천 카드·구간 재생·여러 후보 클립 추가·문장 IN/OUT·모드별 재추천·진행/취소/오류/수동 대안. AG1의 수동 클립 및 승인 결과 보존.
- `electron/analyze.test.ts` + `src/shared/recommendations.test.ts`: 네트워크 없이 가짜 yt-dlp·Whisper/FFmpeg 합성 원본과 결정적 추천/캐시 테스트. [상세](AG2_CLIP_RECOMMENDATIONS.md).
