# 개발 로드맵 · 수용 기준

상태: **2026-10-22 기획 완료 / 코드 구현 미착수**. 예상 일정이나 플랫폼 심사 통과는 아직 약속하지 않습니다.

## Phase 0 — 기술 검증 및 개발 기반

- [ ] `dev` 브랜치 확보, 리포지토리 스캐폴드/자동 테스트/린트/패키징 파이프라인
- [ ] Electron vs Tauri, FFmpeg 내장·GPU 인코딩·macOS/Windows 패키징 검증
- [ ] YouTube IFrame 링크 탐색/타임코드 마커 시연(원본 다운로드에 의존하지 않음)
- [ ] 로컬 영상의 9:16 1080p 렌더 성능 및 정확성 검증
- [ ] SNS 앱 등록/업로드 권한/심사 난이도 확인

**Exit:** 데스크톱에서 로컬 샘플 열기 → 원하는 30초 구간 선택 → FFmpeg 출력/재생 확인.

## Phase 1 — 동작하는 편집/익스포트 P0

- [ ] Project/MediaAsset/Clip/Composition 저장·재열기
- [ ] 로컬 파일/YouTube 임베드 탐색 + 원본 미연결 상태/재연결
- [ ] In/Out/루프/여러 후보, 기본 9:16 크롭, 렌더 진행/취소/재시도
- [ ] 자동 자막 + 수정 + 3–4개 기본 템플릿
- [ ] 기본 TTS 나레이션과 오디오 믹스, 나레이션 OFF 유지
- [ ] 기본 CTA OFF/오버레이/엔드카드 및 최종 길이 검사
- [ ] **선언형 스타일 카탈로그 + 버전 스냅샷**
- [ ] MP4 익스포트 + 결과 확인

**Exit:** 30분 원본에서 3개 클립을 만들고 저장·재열기·서로 다른 자막/CTA/나레이션 설정으로 MP4 익스포트.

## Phase 2 — 공식 YouTube 배포 P0

- [ ] 최소 OAuth 권한 요청, 계정 연결/해제, 시크릿 안전 보관
- [ ] 사용자 승인 → YouTube 업로드 → 처리/게시 상태 확인
- [ ] 인증 만료·업로드 실패·중복 방지·수동 파일 게시 fallback

**Exit:** 테스트 계정으로 승인된 영상 게시 후 게시 URL과 상태를 정확히 기록.

## Phase 3 — AI 추천·Trend Studio·CTA 고도화 P1

- [ ] STT/대본·장면 기반 후보 추천, 스마트 인물 크롭, 묶음 익스포트
- [ ] 공식·허가된 트렌드 신호 수집과 증거/신뢰도 관리
- [ ] 자동 스타일 생성→샘플 렌더→보안·호환·라이선스 검증→원격 배포/롤백
- [ ] 나레이션 톤/자막 모션·효과음·크롭이 묶인 동적 StyleBundle
- [ ] CTA 브랜드 키트, TTS, 플랫폼별 문구/안전 영역 검증
- [ ] Instagram/TikTok 심사/허가 조건 충족 시 플랫폼 어댑터 연동

**Exit:** 새 프리셋은 앱 재설치 없이 등장하지만 기존 프로젝트는 안 바뀌고, 오류 프리셋은 차단·롤백됨.

## Phase 4 — 수요 검증 이후 SaaS/확장 P2

- [ ] 선택적 클라우드 렌더/웹 편집, 프로젝트 동기화
- [ ] 예약 게시·팀 승인·계정별 브랜드 템플릿
- [ ] 권한·동의 기반 게시 성과 및 CTA 실험

**Exit:** 로컬 렌더와 클라우드 렌더 사이에 Composition/RenderManifest 계약을 공유하고 원가·보존·권한 정책을 확인.

## 공통 출시 게이트

- 원본이 없을 때 URL 탐색을 렌더 가능으로 오인시키지 않음.
- 스타일 원격 수정/철회가 사용자 콘텐츠를 동의 없이 변경하지 않음.
- 한글·영어 자막이 플랫폼 UI/화면 바깥에 잘리지 않음.
- CTA 오버레이와 엔드카드의 시간 계산 및 음성 믹스 일치.
- 네트워크/AI 오류에도 핵심 로컬 프로젝트 편집·익스포트 경로 유지.
- 게시 승인 없이는 외부 업로드가 시작되지 않고 중복 게시 없음.
- 모든 기능 변경은 README·관련 문서·테스트/구현 상태 반영.
