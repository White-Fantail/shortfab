# Trend Studio — 자동으로 확장되는 편집 스타일

상위 기준: [PRODUCT_BLUEPRINT.md](PRODUCT_BLUEPRINT.md) §8A. 상태: **기획/미구현**.

## 목적

앱 업데이트 없이 최신 편집 방식을 **선택 가능한 옵션**으로 공급합니다. 사용자가 이미 만든 프로젝트의 프리셋은 자동으로 바뀌지 않습니다. `최신 스타일`과 **실증 데이터가 있는** `트렌딩` 레이블을 구분합니다.

## 스타일 구성요소

- Subtitle: 글꼴, 언어별 줄바꿈, 줄/단어 강조, 자막 위치·색상·윤곽, 모션, 안전 영역.
- Narration: 원고 톤, 말 속도, 호흡/쉼표, TTS 보이스 요구조건, 원본 음성과 믹싱.
- Pacing & Video: 컷 템포, 크롭, 화면 전환, 후킹 타이틀/카드.
- Sound: 효과음/음악 자산 참조, 권리 메타데이터, 게인/덕킹.
- CTA: 종류와 스타일 기본값. 사용자 설정 및 플랫폼별 문구가 우선.
- Compatibility: 최소 렌더 엔진 버전, 필요한 플러그인 기능(허용된 기능 식별자), 비율/언어/공급자 지원.

## 후보 수집 → 원격 카탈로그 게시

`허가된 신호 수집 → 패턴 도출 → 선언형 스타일 생성 → 스키마·보안·라이선스 검증 → 샘플 렌더/QC → 서명·버전 → 점진적 배포 → 롤백/철회`

- 신호 출처·수집일·지역·언어·플랫폼·접근권한·근거·신뢰도를 기록합니다. 트렌드 증거(예: 공식 인기 동영상의 메타데이터)만으로 세부 편집 방식까지 자동 추출 가능하다고 가정하지 않습니다.
- 허락된 레퍼런스에서 편집 패턴을 **추상화**하되 타인의 고유 영상·사운드·브랜드를 복제하지 않습니다.
- AI는 허용 스키마의 데이터만 생성. 인터넷에서 받아온 코드를 실행하거나 실행 플러그인을 설치하지 않습니다.
- 스키마/폰트·한국어·영어/자막 안전영역/과도한 깜빡임/음량·길이/9:16·1:1 렌더 테스트 및 자산 라이선스 심사를 통과해야 활성화할 수 있습니다.
- 자동 QC로 판단하기 어려운 모방·저작권·법률 위험은 인간 검토 상태로 유지합니다.
- 운영 제안: 일간 신호, 주간 후보 평가·검증, 검증 통과 시 배포, 월간 추천 순위 재평가.

## 상태 모델

`candidate → validating → [active | review_required | rejected] → deprecated/revoked`

- active 버전은 불변. 업데이트는 새로운 version/hash로 게시.
- 프로젝트는 `styleBundleId`, `version`, `hash`, `resolvedParameters`를 스냅샷으로 저장.
- 원격 서명 실패/버전 비호환/자산 권리 만료 시 해당 신규 스타일 적용을 차단하고 마지막 정상 스냅샷을 사용하거나 사용자 조치를 요청.
- `revoke`는 신규 적용 중지, 기존 프로젝트에 영향이 있으면 사유 고지 및 안전한 대체 렌더 경로 제공.

## 선언형 계약 예시 (설명용, 확정 스키마 아님)

```json
{
  "id": "dynamic-knowledge-01",
  "version": "1.0.0",
  "minEngineVersion": "0.1.0",
  "supportedRatios": ["9:16", "1:1"],
  "subtitle": { "layout": "two-line", "emphasis": "keyword", "motion": "pop" },
  "narration": { "mode": "optional", "tone": "concise", "speed": 1.05 },
  "video": { "pacing": "fast", "focus": "speaker" },
  "cta": { "enabledByDefault": false, "type": "overlay", "goal": "follow" },
  "assets": [],
  "evidence": [],
  "signature": "<signed-manifest-reference>"
}
```

서명 형식·실제 키·신뢰 루트는 구현 전에 별도 ADR로 정하고, 모형 문자열을 실사용 신뢰검증으로 착각하지 않습니다.

## 수용 테스트

- 앱 업데이트 없이 검증된 스타일 신규 버전이 목록에 추가된다.
- 동일한 프로젝트를 재열어도 과거 선택 스타일·사용자 변경값은 그대로다.
- 스키마에 미지원 필드/실행 코드/서명 불일치가 있으면 적용이 차단된다.
- 오프라인에서도 이미 검증·캐시한 스타일은 재사용 가능하다.
- 한국어 두 줄/영어 줄바꿈/움직이는 자막/CTA가 화면 밖으로 나가지 않는다.
- 출처 증거가 없는 스타일에는 `트렌딩` 배지를 표시하지 않는다.
