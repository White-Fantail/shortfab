# Trend Studio v2.0 — AI Guided Creation에 통합되는 스타일 추천

- 상태: **목표 설계**. 기존 자막 4종은 코드로 구현되어 있으나 동적 원격 트렌드/추천 시스템은 미구현.
- 기준: [제품 기획](PRODUCT_BLUEPRINT.md), [UX](UX_WORKFLOWS.md), [로드맵](ROADMAP.md).

## 역할 변경

기존 '스타일 카탈로그에 들어가 찾아서 고르는' 별도 편집 공간이 아니라 **현재 단계에서 AI가 콘텐츠에 맞는 스타일 2~3개를 먼저 보여주는 추천 공급자**로 설계한다. 트렌드 라이브러리 전체 목록은 고급 선택지로 남긴다. 사용자가 자막/음성/CTA/화면을 각각 승인하면 그 값이 전역 프리셋 변경에도 보존되어야 한다.

## 스타일 구성

- 자막: 텍스트/단어 강조, 폰트·언어별 줄바꿈, 모션·색·위치·배경 및 안전영역.
- 영상: 컷 템포, 9:16 배치/크롭, 패닝·분할 전환, Hook 카드.
- 사운드: TTS 목소리의 톤/속도, 원본 덕킹, 권리 확인된 효과음/BGM.
- CTA: 오버레이/엔드카드 형식, 폰트/브랜드, 플랫폼 별 안전영역.
- 버전: StyleBundle(id,version,minRendererVersion,requiredFeatures,sourceEvidence,licenseRefs,caption,layout,audio,cta).

## 제작 단계와의 계약

1. 영상 언어/주제/길이/플랫폼/선호 스타일을 기반으로 추천 2~3개.
2. 작은 카드에 샘플 프리뷰와 '이 클립에 적합한 이유' 표시.
3. '이대로 사용' 시 **현재 단계의 해당 필드만** 적용한다. 다른 단계에서 승인한 수동 수정 잠금은 유지.
4. '다시 추천' 시 새 초안 생성, 기존 승인값은 새 카드 채택 전 유지.
5. '더 보기'에서 전체 라이브러리/고급 파라미터. 새 스타일이 배포되어도 기존 프로젝트의 **핀된 버전은 자동 변경 금지**.

## 자동 스타일 수집/출시 파이프라인 (AG8)

허가된 콘텐츠/플랫폼 정보·사용자 피드백 → 패턴 추상화 → 선언형 후보 생성 → 라이선스·안전성·폰트/언어 스키마 검증 → 실제 테스트 샘플 렌더 → 서명/버전 게시 → 점진 출시 → 철회/롤백.

수집한 조회수 등의 신호는 편집 효과의 인과 증거가 아니다. '새로 추가됨'과 객관적 근거를 확보한 '인기 있음'을 구분한다. 타인 고유의 영상·오디오·워터마크/브랜드를 복제하지 않는다. 동적 JS/임의 바이너리 다운로드는 허용하지 않는다.

## 우선순위/수용

AG4에는 **현재 포함된 4종 자막을 활용한 자동 추천 2~3안** 먼저. 대규모 실시간 트렌드 수집/원격 카탈로그는 AG8. 한영 폰트/안전영역, 과도한 깜빡임/피로, BGM 권리, 동일 FFmpeg 출력 QC, 승인값/수동 오버라이드 유지가 출시 게이트다.
