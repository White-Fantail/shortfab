# ShortFab 제품 기획 v2.0 — AI Guided Creation

- 결정: 2026-10-22. **목표 기획이며 신규 기능 구현 완료를 의미하지 않는다.**
- 기준: [UX_WORKFLOWS](UX_WORKFLOWS.md), [ROADMAP](ROADMAP.md), [ARCHITECTURE](ARCHITECTURE.md), [IMPLEMENTATION_STATUS](IMPLEMENTATION_STATUS.md)
- 태그라인: **AI creates. You refine. ShortFab finishes.**

## 1. 제품 정의

ShortFab은 **기존 YouTube 영상 URL을 입력하면 AI가 단계마다 쇼츠의 초안을 제안하고, 사용자는 필요한 부분만 수정·승인해 MP4를 완성하는 도구**다. 일반 영상 편집기가 아니라 **AI 주도·사용자 승인형 쇼츠 제작 마법사**다. 사용자가 원본 MP4를 제작·소유하거나 타임라인 사용법을 알 필요가 없어야 한다.

**이전 기획에서 변경:** AI 클립 추천을 후기 Phase 3로 미루던 결정을 폐기한다. **화면 배치는 자동 결정하지 않고 스타일 카드에서 사용자가 직접 고르도록 2026-10-22에 변경했다.** 빈 편집기, 항상 보이는 3열 소스/타임라인/출력 패널을 기본 진입 경로로 삼지 않는다. 기존 수동 편집 기능은 Advanced Edit로 보존한다.

## 2. 사용자 목표 및 원칙

- URL을 한 번 붙여넣으면 별도 구간 조작 없이 **추천 클립이 먼저** 나타난다.
- 각 단계의 공통 흐름: **원본 분석/추천(클립) 또는 스타일 카드 시안(화면·자막 등) → 시안 비교 → 스타일 선택/조금 수정 → 승인하고 다음**. 완전 렌더 동등 재생형 미리보기는 후속이며 현재 정지 프레임 시안과 구분한다.
- 사용자가 고친/승인한 값은 뒤로 가기, 재생성, 프로젝트 재열기에서도 유지한다.
- 추천 근거와 원본 발췌를 보여주되, 임의의 바이럴 성공률을 객관적 사실처럼 표시하지 않는다.
- 중간에 언제든 종료/재개 가능. 여러 클립은 원본 분석은 공유하되 승인·렌더 상태는 독립.
- 모든 자동화 실패에는 기존 상태 보존·재시도·가능한 수동 대안을 제공한다.
- AI와 자동 렌더는 사용자를 대신해 **SNS 게시 승인**을 하지 않는다.

## 3. 핵심 사용자 여정 — 8단계

| 단계 | AI가 먼저 하는 일 | 사용자가 확인·수정하는 것 | 승인 산출물 |
|---|---|---|---|
| 01 원본 | URL 검사, 미디어 상태 확인, 전사/장면 분석 | URL, 선택형 목적 프롬프트 | SourceAnalysis |
| 02 클립 | 5~10개 의미 있는 구간 추천·제목·발췌·이유 | 후보 선택, 문장 선택/앞뒤 미세 조정 | ClipSelection |
| 03 화면 | 화면 스타일 카드 4종 이상 좌우 슬라이드·실제 클립 정지 프레임 시안 | 화면 카드 선택, 가로 초점/크롭 미세 수정 | LayoutStyle + OutputSpec |
| 04 자막 | STT 결과와 자막 스타일 카드 슬라이드, 향후 강조·Hook 제안 | 카드 선택, 오탈자·표현·위치 | CaptionPlan |
| 05 소리 | 원본 음성 평가, 필요한 경우 나레이션·음악 제안 | 원고, TTS 음성, BGM/볼륨 | AudioPlan |
| 06 CTA | 플랫폼/목적별 문구와 유형 또는 OFF | 문구·시간·오버레이/엔드카드 | CTAPlan |
| 07 검토 | 구성 합성 프리뷰, 잘림·싱크·길이 품질 검사 | 전체 결과 확인, 단계로 돌아가 수정 | ApprovedComposition |
| 08 출력 | 승인 스냅샷 MP4, 게시 문구 추천 | 저장, 권리 및 별도 업로드 승인 | RenderArtifact / PublishJob |

**선택형 단계:** 나레이션이나 CTA는 언제든 OFF. 기본 CTA OFF이며 원본 대사만으로 충분하면 AI가 나레이션 OFF를 추천해도 된다.

## 4. 단계별 AI 품질 기준

**클립:** 유효한 IN/OUT, 발화의 시작과 끝, 문맥, 침묵·중복, 주제 전환·훅을 고려한다. 발화형은 Whisper 전사를 활용하고, 게임/무음은 후속 장면·OCR·음향 이벤트 분석으로 확장한다. 대본 문장을 선택해서 범위를 바꾸거나 슬라이더로 미세 조정한다. 후보 점수는 휴리스틱/추천 이유로 설명한다.

**화면:** 사용자는 기본 9:16 레이아웃 카드(중앙·왼쪽·오른쪽 크롭, 흐린 배경 원본 전체)를 같은 클립의 정지 프레임 시안으로 넘겨 보며 직접 선택하고 초점을 조정한다. 초기 카드는 참고용 썸네일로 보일 수 있다. 실제 FFmpeg 출력과 일치하는 최종 재생형 프리뷰는 후속으로 검증해야 한다. 자동 얼굴 추적·화자 분할은 기본 흐름/AG3 완료 조건이 아니다.

**자막:** 기존 로컬 Whisper/AG2 음성 분석 재사용으로 실제 대사에서 자막을 만들고, 8종 카드 스타일·Wizard 내 문장/타임코드 수정·선택형 Hook/강조 제안까지 dev 코드에 구현했다. 이후 트렌드 스타일·카라오케 단어별 싱크를 확장한다. 교정한 텍스트를 AI 재생성이 덮어쓰지 않는다. 한국어·영어 폰트, 줄바꿈 및 플랫폼 안전 영역을 검증한다.

**음성:** 원본 오디오 우선, 대사가 충분하면 추가 나레이션을 넣지 않는다. 필요할 때만 TTS 원고/미리듣기와 음원 라이선스 확인된 BGM·효과음, 덕킹·믹싱. 비용/원격 전송 여부는 명시한다.

**CTA:** 없음을 포함한 후보, 구독/팔로우/풀영상/다음편, 오버레이/엔드카드/선택형 음성, 플랫폼별 문구/안전 영역/최종 길이 반영. 화면 속 가짜 링크·버튼을 실제 클릭 가능으로 설명하지 않는다.

## 5. 기본 UI·모드

**홈**은 큰 YouTube URL 입력과 선택형 목표 프롬프트, 최근 프로젝트만 강조한다. **제작**은 상단 8단계 진행바 + 현재 단계의 추천 카드 + 계속 보이는 세로 프리뷰 + 승인/이전. **고급 편집**은 명시적 진입 버튼에서만 IN/OUT 타임라인, 세부 크롭, 자막 시각/오디오 믹서를 노출한다. 모드 전환은 같은 데이터 모델을 사용한다. UX 상세 [별도 문서](UX_WORKFLOWS.md).

## 6. 상태·재생성·저장

- 프로젝트 단위 URL·공통 분석, 클립 단위 단계 스냅샷.
- 상태: not_started / generating / proposed / accepted / needs_review / failed / skipped.
- AI 초안과 사용자 승인값 및 수동 잠금 필드를 분리. '다시 생성'은 잠그지 않은 AI 소유 필드만 갱신하며 기존 결과는 복구 가능.
- 클립 구간 변경 시 화면/자막/소리/CTA/검토를 필요한 범위만 needs_review. 단순 자막 스타일 변경으로 원본 분석을 초기화하지 않는다.
- 완료된 결과의 렌더 서명/버전이 바뀌면 이전 MP4를 새 구성의 출력물로 표시하거나 게시하지 않는다.
- 기존 저장 프로젝트는 하위호환 마이그레이션. 이전 수동 제작 데이터가 사라지면 안 된다.

## 7. 기술·권리·출시 경계

2026-10-22 현재 Electron/React/TS, 로컬 프로젝트 JSON, 공식 YouTube IFrame 탐색, yt-dlp 공개 영상 개인용 캐시, FFmpeg 구간 MP4 출력, 기본 자막·Whisper 코드, YouTube OAuth/업로드 기초 코드가 있다. **URL→선택 클립→실제 MP4 출력은 사용자 실기 성공(1건 이상)**. 새 8단계 Wizard·AG2 음성 기반 추천·AG3 스타일 카드/레이아웃 합성·AG4 자막/Hook은 **dev 코드 반영 및 CI 통과, 사용자 실기 미수용** 상태다. 스마트 자동 인물 배치는 핵심 흐름에서 제외했고 TTS·CTA·재생형 렌더 동등 프리뷰는 미구현이다. 실제 다국어 STT/3개 클립·패키징·게시 실기 역시 별도 검증한다.

YouTube 공개 URL이 임의 다운로드/변경·재게시 권리까지 보장하지 않으며, YouTube 공식 API는 범용 MP4 다운로드 API가 아니다. 개인용 직접 출력과 허가 원본(YF-1)/파트너(YF-2) 경로를 구분한다. 게시 시에는 별도 최종 승인·계정/저작권 검증이 필요하다.

## 8. 성공 측정·수용

- 사용자가 타임라인을 열지 않고 URL→후보 선택→각 단계의 소폭 수정→MP4를 완료할 수 있는가.
- 30분 내외 발화형 실제 영상에서 유효한 여러 추천 구간과 추천 이유, 3개 이상 클립 구성/재열기/출력 가능 여부(가능한 영상에서).
- 단계 뒤로가기·재생성·사용자 잠금·다중 클립 분리·오프라인 오류에서 사용자 변경사항 보존.
- 프리뷰와 MP4의 자막·레이아웃·오디오·CTA 일치. 분석 시간/승인율/수정량/출력 성공률은 실제 측정 후 목표 설정.
