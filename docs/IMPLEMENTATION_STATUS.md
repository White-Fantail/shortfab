# ShortFab 구현 및 수용 상태 · 2026-10-22

> **기준:** 사용자 앱에서 **YouTube URL을 이용한 클립 MP4 익스포트 성공**을 확인받음(2026-10-22). 사용자 확인은 실제 조작 성공에 대한 보고이며, 모든 영상·기기·네트워크에서의 범용 성공이나 공식 플랫폼 권한 검증을 뜻하지 않음.

이 문서는 기획된 기능, 코드 구현, 자동 테스트, 사용자 실기 확인을 분리한 **현재 상태의 단일 요약**입니다. 구현을 변경하면 각 기능의 체크리스트 및 [로드맵](ROADMAP.md)을 함께 수정합니다.

## 제품 v2.0 전환 현황 (2026-10-22)

**기획/문서 확정 ≠ 새 UI/AI 기능 구현 완료.** [ADR-0004](adr/0004-ai-guided-creation.md)에 따라 ShortFab의 신규 기본 UX를 **8단계 AI 제작 마법사**로 전환하기로 결정했다. 현재 코드의 YouTube URL→수동 구간 지정→MP4 출력 성공은 그대로 유지한다. 전문 편집 UI는 dev 브랜치에서 Advanced Edit 모드로 분리했다.

## AG1 코드 변경 / 미완료 범위 (2026-10-22)

- `src/WizardPanel.tsx`: 기존 기본 3열 편집기 대신 별도 8단계 제작 작업 영역, 선택 단계만 표시하는 카드·단계별 승인/이전/선택적 건너뛰기. 소스 URL·재생 위치 기반 수동 클립 추가/구간 수정, 현재 실제 지원 가능한 중앙 크롭/자막/원본 소리/CTA OFF 구성, MP4 출력 실행.
- `src/App.tsx`: 기본 Wizard와 숨겨진 Advanced Edit가 **동일 클립/상태/저장 경로**를 사용하며, 기존 IFrame 탐색/FFmpeg 출력/고급 게시 폼은 계속 접근 가능. 실제 플레이어는 YouTube **원본 참고**, 합성 프리뷰가 아님.
- `src/shared/wizard.ts` 및 `src/shared/projects.ts`: 프로젝트 스키마 v1을 유지한 선택형 `wizard` 저장 필드, 구 JSON 파일 기본 상태 마이그레이션, clipId별 독립된 상태, proposed vs approved 분리, 사용자 필드 잠금·제안 버전·needs_review 의존 무효화. 앱 중단된 generating 상태는 재열 때 failed로 취급하며 다시 실행 대기.
- `src/shared/wizard.test.ts`: 이전 JSON/클립 상태 격리, 제안 버전, 잠금 유지, 변경 전파, 삭제 클립 정리, 실행 중 단절 및 잘못된 스키마 거부 검사.
- **한계:** AG2 자동 전사/클립 추천은 실제 로컬 엔진으로 연결됐지만 AI 레이아웃 재생성은 비활성화. 기존 로컬 Whisper는 자막 단계에서 호출할 수 있으나 고급 편집의 전체 교정 UI가 필요. TTS/BGM/CTA 실제 합성은 여전히 없음.
- **수용 미완료:** macOS/Windows에서 8단계 승인·되돌리기·재열기·고급 편집 왕복 및 MP4 사용자 시나리오 확인. 실제 YouTube 영상 접근 및 실제 한국어·영어 GGML 모델 추천 품질 수용은 미실시. 단위/빌드 CI 통과는 실제 소스 수용 증명이 아님.

## AG2 원본 분석/클립 추천 (2026-10-22 · 코드 상태)

- **실제 코드:** `electron/analyze.ts`, `electron/stt.ts`, `electron/main.ts`, `electron/preload.ts`, `src/shared/recommendations.ts`, `src/WizardPanel.tsx`, `src/App.tsx`.
- **작동:** AG1 Wizard의 02 클립 단계에서 실제 공개 YouTube 원본 캐시 획득 → 오디오 유무 확인 → `whisper-cli`로 9분 이하 조각 전사(최초 60분 상한) → 상대 시간 SRT를 원본 절대 타임코드로 정리 → 질문/반전/대사 연속성·길이에 따른 최대 8개 후보·진짜 대사·추천 이유 → 구간 플레이어 확인/멀티 선택/문장 IN·OUT 미세 수정 → 기존 승인 단계에서 수동 승인 후 MP4. 자막 전용 30큐 제한과 분리.
- **실사용 UX:** Whisper 모델 설치 버튼/언어(자동/한국어/영어)/진행률/취소/에러/원본 재분석, 캐시 기반 더 짧게·더 역동적으로 재추천. 후보만 새로 만들며 기존 수동 수정 클립은 보존. 음성·대사가 부족하거나 URL 접근 불가이면 대체 수동 클립 선택.
- **캐시:** 사용자 데이터의 `analysis/` 아래 videoId·언어·모델 지문/분석 엔진 버전별 JSON을 제한된 크기로 기록. 모델이 바뀌거나 원본 길이가 달라진 경우 재분석. 경로·모델 파일은 IPC에서 노출하지 않음.
- **테스트:** 결정적 SRT/추천 함수 단위 테스트, 실제 FFmpeg 합성 원본 + 가짜 Whisper/yt-dlp의 오프라인 종단 흐름 및 캐시 재사용 테스트. 자동 테스트 성공은 실제 Whisper 모델 언어 인식 정확도를 입증하지 않음.
- **남은 범위:** 실제 한국어·영어 발화형 YouTube 영상 추천 품질·속도/메모리·외부 다운로드 실패·길이 60분 영상 실기, 장면 키프레임 탐색/비언어 클립 모델 및 선택형 LLM 랭킹 미구현. 사용자 수용 전 AG2 전체 완료 표기 금지. [개발/실기 체크](AG2_CLIP_RECOMMENDATIONS.md).

## 확인된 핵심 P0 흐름

```text
YouTube URL
  → IFrame 영상 탐색
  → IN/OUT 구간 후보 저장·선택
  → MP4 익스포트 명령
  → 로컬 yt-dlp 공개 영상 취득/캐시
  → FFmpeg 9:16 클립 출력
  → 사용자: MP4 익스포트 성공 확인 (2026-10-22)
```

**완료 범위:** 개인용 앱에서 적어도 한 번 위 흐름으로 MP4 익스포트가 성공했습니다. 이로써 이전에 존재했던 **“YouTube에서 탐색만 되고 MP4 출력은 불가”** 핵심 장애는 해당 검증 환경에서 해결된 것으로 기록합니다.

**완료로 간주하지 않는 사항:** 서로 다른 실제 클립 3개 출력·캐시 재사용·실기 FFprobe/오디오 싱크 QC, 다양한 URL/지역/제한 영상, Windows/배포용 macOS 설치 패키지, 저작권 및 YouTube 이용약관 충족 여부, SNS 계정 연동/실제 게시. **사용자 성공 보고만으로 미실시 시험을 완료 처리하지 않습니다.**

## 완료된 주요 UI 개선

- 기본 YouTube 입력 및 공식 IFrame 미리보기, 구간 후보와 출력 탭을 한 화면에서 사용
- 앱 타임라인에 `현재 MM:SS / 전체 MM:SS`를 상시 표시, 재생/일시정지 버튼 배치
- IFrame 기본 진행 바와 앱 진행 바의 중복 제거, 스크럽 중 오래된 시각으로 되돌아가는 문제에 대한 코드/테스트 보완
- 장황한 개인용 원본 안내 및 권리자·파트너 설정을 기본 접기 패널로 분리하고 동일한 간결한 화살표 디자인으로 통일
- 클립 저장 중 이름/구간이 일시적으로 부적절할 때 검증 오류를 반복 노출하지 않도록 저장 대기/유효성 흐름 개선

## 2026-10-22 Phase 1 자막 코드 변경

- 클립별 수동 자막 텍스트, 상대 구간, 내장 스타일 4개를 JSON 저장/재열기 시 검증합니다. 기존 프로젝트는 자막 없음으로 열립니다.
- FFmpeg libass가 있는 환경에서만 자막 합성이 가능하고 임시 ASS 파일은 사용 후 제거합니다. 자막 없는 출력은 종전 경로를 재사용합니다.
- 출력 파일과 현재 자막 편집본의 일치 확인을 통해 수정 후 오래된 MP4의 게시 승인을 차단합니다.
- **검증 경계:** 단위 및 합성 FFmpeg 통합 테스트, 타입·린트·빌드가 [CI 실행](https://github.com/White-Fantail/shortfab/actions/runs/39711971165)에서 통과. Mac/Windows 한글/줄바꿈 실기 검증 대기. 자동 STT, TTS, CTA 및 카탈로그 동적 배포는 미완료.

## Phase 1 · 로컬 Whisper.cpp 음성 인식 추가 (2026-10-22)

- 기존 YouTube 개인 캐시·승인 바인딩 또는 로컬 파일에서 **선택 클립의 음성만 추출**해 로컬 `whisper-cli`로 한국어/영어/자동 인식 SRT를 생성하도록 메인 프로세스 작업 큐에 연결.
- CLI 설치 상태와 GGML 모델 경로는 메인 프로세스에서만 검사·저장하며 UI에는 성공 상태/파일명만 표시. 앱 버튼으로 다국어 모델(약 148MB)을 사용자 동의 후 공식 Hugging Face에서 내려받아 크기·SHA-256을 검사하며 취소·15분 제한 시간·손상 파일 정리·캐시 재사용을 지원. 임시 WAV/SRT와 전사 데이터는 외부 STT 서비스에 전송하지 않고 작업 후 정리.
- **기존 자막을 자동으로 덮어쓰지 않음:** UI에서 교체 의사를 확인하고, 처리 실패·취소 시 이전 자막 유지. 성공 이후 자막/스타일은 수동 수정 및 MP4 번인 경로와 호환.
- **코드/자동 테스트 CI 성공** ([기존 로컬 STT 통과](https://github.com/White-Fantail/shortfab/actions/runs/39713985829)). 기본 모델 다운로드 검증/취소 테스트는 별도로 추가했으며 해당 변경의 CI 및 실제 GGML 추론·Mac/Windows UI, 음성 정확도·속도는 각각 확인해야 합니다. 설정과 제한은 [STT 문서](STT_LOCAL.md).

## 과거 기술 로드맵의 다음 개발 우선순위 (신규 작업 우선순위는 상단 AG0~AG7 적용)
