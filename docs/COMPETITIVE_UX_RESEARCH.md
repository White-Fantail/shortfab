## UX 차별화 가설

많은 도구는 **한꺼번에 자동 생성한 후 기존 편집기에서 수정**하거나 **기존 편집기에 AI 도구를 추가**한다. ShortFab은 기본적으로 **AI 초안을 단계별로 보여주고 사용자가 그 단계만 다듬고 승인**한다. 경쟁 서비스에 같은 방식이 전혀 없다는 단정은 하지 않는다.

1. **첫 사용자 행동:** URL 붙여넣기. 타임라인에서 IN/OUT을 처음부터 입력하지 않음.
2. **AI 추천:** 타임코드·제목·발췌·이유가 있는 클립 카드.
3. **장면 지능:** 클립별 자동 화면 배치와 수정 가능한 제안.
4. **자막·소리·CTA:** 매 단계 실제 선택 가능한 초안, 사용자 교정 보존.
5. **최종 책임:** 합성 결과 검토/출력, SNS 업로드 별도 승인.

## 경쟁 UX 후속 수용 실험

권리가 확인된 동일한 10~30분 영상(한국어 대담, 영어 대담, 2인/게임/무음)을 각 서비스에 입력하여 **첫 후보 표시 시간, 사용자의 클릭 수, 첫 승인까지 소요, 자막/크롭 수정 비용, 결과 MP4 품질, 버전 보존, 게시 승인 경계**를 기록한다. 마케팅 설명과 직접 조작 증거를 분리하고 워터마크·크레딧·콘텐츠 권리 조건을 재검증한다.

**채택 결론:** OpusClip식 추천 + Klap식 화면 재구성 + Descript식 대본 수정 + Captions식 간단한 재생성을 조합하되, 사용자 기본 여정은 [8단계 마법사](UX_WORKFLOWS.md)로 독립 설계한다.
