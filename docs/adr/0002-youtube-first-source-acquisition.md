# ADR-0002: YouTube URL-first + 권한 기반 원본 확보 전략

- Date: 2026-10-22
- Status: **제품 목표 승인 / 구체 미디어 취득 수단은 검증 필요**
- Supersedes: 기존 문서의 **로컬 파일이 1차 주력이며 YouTube는 탐색용 보조**라는 제품 우선순위. ADR-0001의 로컬 우선 **렌더 아키텍처** 자체는 유지함.
- Detailed design: [YOUTUBE_FIRST_WORKFLOW.md](../YOUTUBE_FIRST_WORKFLOW.md)

## 배경

사용자는 영상의 직접 촬영자나 원본 MP4 보유자가 아니다. 핵심 JTBD는 **YouTube에서 발견한 기존 영상 URL로 시작해, 가치 있는 구간을 추출·재편집하여 새 숏폼을 만드는 것**이다. 현재 앱은 로컬 영상 없이는 새 MP4를 렌더할 수 없어 핵심 사용자 요구를 충족하지 못한다.

## 결정

1. 제품의 **기본 소스 입력은 YouTube URL**이다. 로컬 파일은 보조 입력/테스트 경로다.
2. YouTube 원본을 **탐색 가능한 참조**(`YouTubeReference`)로 유지하면서, 최종 렌더는 별도 **권한 있는 미디어 바인딩**(`MediaBinding`)이 있어야 허용한다. 이 제약은 구현 편의가 아니라 플랫폼/권리 조건이다.
3. 우선 IFrame Player API로 실제 시각·탐색/후보 마커 기능을 완성한다. 그 후 `SourceResolver`/파트너·허가 원본 저장소 연결을 최우선 개발한다.
4. 사이트에서 단순 공개 영상을 재생할 수 있다는 이유로 독립 MP4 다운로드/재가공 권한이 생기지 않는다. 재편집 라이선스와 YouTube에서의 취득 권한을 별도 확인한다.
5. **yt-dlp 기술 조사 자체는 허용**하지만 현재 정책/인증·안정성 상태에서는 **출시용 기본 YouTube 다운로드 경로로 채택하지 않는다**. 서면 승인이나 명시적으로 허용되는 절차 확인 시 별도 ADR로 재평가한다. 쿠키 수집·PO 토큰 우회·DRM 회피를 개발 필수 요건으로 만들지 않는다.
6. 공식 Clips/Shorts Remix는 새 MP4 export 대체가 아니라 **YouTube 안에서 허용된 공유 또는 이동 경로**로 구분한다.
7. Phase 0/1의 로컬 렌더 완료와 Phase 2의 YouTube 업로드 기능은 **링크→새 클립 제작 성공을 입증하지 않는다**. 공식 로드맵에서 이 차이를 차단 출시 게이트로 명시한다.

## 제품·개발 영향

- 프로젝트 핵심 엔티티 추가: `YouTubeReference`, `SourceResolution`, `RightsGrant`, `MediaBinding`, `SourceResolver`.
- UX는 `YouTube URL → 구간 선택 → 원본 확보 상태 → MP4 → 게시`. 원본 확보 실패 시 탐색·저장/공유 기능을 유지한다.
- Electron 파일/렌더 경로는 계속 로컬 우선이다. YouTube IFrame에서 실제 영상 URL을 추출해 렌더러/워커로 전달하지 않는다.
- **출시 결정에 필요한 검증:** 대표 제3자 동영상/권한 제공자 경로의 계약 적합성, 최종 MP4 생성, 권리 만료·삭제 시 프로젝트 상태.

## 미해결

- 제작자/파트너가 허가된 원본을 URL과 매칭해 제공하는 자동화 및 계약 모델
- 일반 외부 YouTube 채널 영상에 대해 합법적으로 자동 다운로드 가능한 범위
- 구간별 권리와 BGM/초상/음원 등 하위 라이선스 확인, 국가·플랫폼별 차이
- 공식 Clips 생성 자동화/딥링크 지원 범위와 API 안정성

**구현이 완료되기 전까지 "어떤 YouTube URL이든 MP4로 변환"을 제품 문구/완료 체크로 사용하지 않는다.**

## 이후 결정에 따른 범위 제한 (2026-10-22)

본 ADR의 yt-dlp를 기본 제품 경로로 택하지 않는다는 판단은 **배포형/상업용** 기본 제품과 공식 API 설계에 대한 것입니다. 사용자의 개인 로컬 데스크톱 이용 요청으로 공개 영상에 한해 yt-dlp를 사용하는 실험 경로를 별도 추가하였습니다. 이 기술적 구현을 콘텐츠 사용 허가·공식 YouTube 승인으로 취급하지 않습니다. 적용 범위 및 테스트 상태는 [ADR-0003](0003-personal-youtube-clipping.md)를 참조합니다.
