# ADR-0003: Phase 1 프로젝트 로컬 JSON 저장

- Date: 2026-10-22
- Status: **Phase 1 첫 기능 묶음 사용자 확인 완료 (2026-10-22)**; OS별 실기·오류/경합 통합 검증은 별도

## 결정

- 첫 로컬 편집 프로젝트를 SQLite 없이 Electron 사용자 데이터 폴더의 `projects/{uuid}.json`에 스키마 버전 1로 저장한다.
- 파일 메타데이터와 클립 후보의 시작/종료/출력 폭을 비파괴 데이터로 보존한다. 저장소 관리 책임은 Electron 메인 프로세스가 갖고 렌더러는 실제 로컬 경로를 받지 않는다.
- 원본은 앱에 복사하지 않는다. 사용자가 이동하면 원본 연결 상태가 `missing`이 되고, 영상 파일을 명시적으로 다시 선택해야 렌더할 수 있다.
- 원본 재연결은 파일 크기·길이·해상도를 대조하나 강한 파일 동일성 보장은 하지 않는다.
- 프로젝트 편집 저장은 revision을 확인하고 임시 파일을 쓴 뒤 대상 JSON으로 교체한다. 한 번에 편집 중인 프로젝트 하나만 지원한다.

## 이유와 후속 작업

초기 MVP에 외부 서비스나 DB 설치 부담을 주지 않고 저장/다시 열기 UX를 먼저 검증하기 위함이다. 성능, 다중 창, 검색, 마이그레이션이 필요해지면 SQLite 인덱스 및 독립 미디어 자산 카탈로그를 추가할 수 있다.

검증 근거: 사용자 확인 및 GitHub Actions 타입 검사·린트·단위 테스트·빌드 통과 ([CI run](https://github.com/White-Fantail/shortfab/actions/runs/39657881821)).

Phase 1 후속: 프로젝트 마이그레이션 정책, 오디오/자막/CTA 스타일 스냅샷, strong fingerprint, 작업 목록 렌더, 오류 복구와 자동 저장 통합 테스트.
