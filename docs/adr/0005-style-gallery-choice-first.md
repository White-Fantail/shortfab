# ADR-0005 — 프리셋 스타일 카드 선택을 기본 제작 UX로 채택

- 일자: 2026-10-22
- 상태: 채택. [기존 ADR-0004](0004-ai-guided-creation.md)의 **AI 자동 레이아웃 우선** 결정만 대체한다.
- 참고: [제품 기획](../PRODUCT_BLUEPRINT.md) · [STYLE_GALLERY](../STYLE_GALLERY.md) · [로드맵](../ROADMAP.md)

## 사용자 피드백

자동 배치/자막을 AI가 알아서 확정하면 개별 영상의 의도와 브랜드 표현이 맞지 않을 수 있다. 사용자는 기존 YouTube 링크의 쇼츠 생성 과정을 복잡한 영상 편집 없이 **여러 스타일을 카드처럼 넘기며 시각적으로 비교하고 자신이 결정**하길 원한다. 화면·자막·사운드·CTA 모두 같은 선택 UX를 선호한다.

## 결정

- AG3 자동 얼굴/화자 추적 중심 전략을 **4+개의 선언형 화면 스타일 갤러리(선택형)**로 대체한다.
- 시안은 같은 클립의 원본 스틸(없으면 원본 썸네일)을 사용한다. 선택된 ID와 수동 초점을 안전한 클립 JSON에 저장한다.
- 모든 선택형 시안은 가능한 범위에서 FFmpeg/ASS 출력에 실제 반영하며, 참고 정지 이미지와 렌더 동등 재생형 프리뷰를 명확히 구분한다.
- AG4 자막의 이미 존재하는 4종 스타일을 동일 카드 UX로 통합한다. AG5/6도 기능 개발 시 선택 카드 패턴 우선.
- 원격 스타일 업데이트·트렌드 카탈로그는 후속에서 버전·검증·롤백을 제공한다. AI는 후보 순서를 돕는 선택형 보조이지 사용자 동의 없이 승인/덮어쓰지 않는다.
- AG2 실제 전사 기반 클립 추천은 그대로 유지하고 실기 수용 전까지 완료 처리하지 않는다.

## 대안 및 트레이드오프

- 얼굴·화자 인식 기반 자동 배치: 일부 콘텐츠에는 유용하지만 복잡성·실패·품질 검증 비용이 커 기본 선택 경로에서 제외. 고급 기능으로 미래에 선택적으로 연구 가능.
- CSS 목업 카드만 보여 주기: 사용자가 실제 결과를 오해하므로 출력 FFmpeg 연동을 필수 계약으로 둔다.
- 모든 카드마다 완성 MP4를 즉시 렌더: 정확하지만 다운로드/인코딩 비용이 큼. 현재 정지 프레임 기반 카드로 시작하고, 실제 선택 후보에 대한 재생형 프록시/실제 미리보기는 후속 보완.

## 범위와 수용

1차 구현은 화면 레이아웃 4종과 자막 기본 4종 카드, FFmpeg 합성, 정지 프레임 추출, 프로젝트별 저장, 출력 후 변경 시 게시 차단이다. **현재 UI/자동 CI 구현 완료와 실제 macOS/Windows 사용자 영상 수용은 별개**. 최종 AG3 완료 시 실제 파일과 시각적 구도·A/V·자막 상태를 확인한다.
