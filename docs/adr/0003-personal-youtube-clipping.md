# ADR-0003: 개인용 YouTube 공개 영상 클립 직접 출력 실험

- Date: 2026-10-22
- Status: **개인용 프로토타입 구현 / YouTube 실영상·약관 적합성 및 배포 검증 대기**
- Supplements: [ADR-0002](0002-youtube-first-source-acquisition.md)
- Technical implementation: [PERSONAL_YOUTUBE_EXPORT](../PERSONAL_YOUTUBE_EXPORT.md)

## 문제

기존 YF-0/1/2는 YouTube URL로 구간을 고를 수 있지만 MP4 제작 전에 별도 권리자 파일 또는 파트너 카탈로그가 필요했다. 실제 개인 사용자의 핵심 목표인 **링크 하나로 구간을 편집하고 MP4로 저장하기**는 막혀 있었다.

## 결정

1. 배포용 SaaS/멀티테넌트 정책과 구분되는 **개인용 로컬 실험 경로**를 추가한다. 사용자는 공개 YouTube URL을 붙여넣고 공식 IFrame으로 IN/OUT을 고른 뒤 MP4 익스포트 버튼 하나로 해당 공개 영상을 가져와 FFmpeg로 편집할 수 있다.
2. 로컬 실행에 설치된 오픈소스 `yt-dlp` CLI를 `spawn` 인수 배열로만 호출하고, **11자리 영상 ID를 먼저 검증해 정규 YouTube URL을 재구성**한다. 이 프로그램은 사용자의 명령으로 실행하며, 로그인 쿠키·DRM·접근 제한 우회 기능을 추가하지 않는다.
3. 선택 시각에 해당하는 클립을 기존 FFmpeg 렌더러로 제작하고, 다운로드한 전체 영상은 앱 로컬 개인 캐시에 남겨 후속 클립에서 재사용한다. 캐시의 사용자 데이터·디스크 비용과 삭제 기능은 후속 개선 대상이다.
4. **다운로드가 기술적으로 가능하다는 사실은 콘텐츠 다운로드 또는 재게시 사용권의 존재를 의미하지 않는다.** 개인적 사용도 해당 서비스 약관과 저작권을 검토해야 하며, 이를 인증된 권리 보유 상태로 표시하지 않는다.
5. 개인용 다운로드 결과는 `sourceBindingId: youtube:<videoId>`로 구별하며, 권리자 승인 바인딩을 가진 출력과 혼동하지 않는다. **자동 YouTube 업로드는 기존 명시적 재게시 사용권 검증을 통과한 작업에만 허용**한다.
6. 승인된 로컬 파일·클라우드·서명 파트너 카탈로그(YF-1/2)는 고급 소스 연결로 유지한다. 배포/판매/멀티유저 기능에 임의 YouTube 다운로더를 그대로 적용한다고 결정하지 않는다.

## 위험·수용

- 기술 리스크: YouTube 추출 방식·지역/권한/브라우저 JS 변화로 실패할 수 있다. yt-dlp와 FFmpeg 로컬 설치가 필요하며 OS 패키징은 후속.
- 법적·플랫폼 리스크: YouTube 이용약관은 콘텐츠 다운로드 제한을 둘 수 있으며, 개인용이라도 자동 예외가 되지 않는다. 이용 허가 확인과 재게시 금지를 명시한다.
- 프로젝트 무결성: 영상 식별자/IN/OUT/해상도를 저장 전후 다시 검사, 캐시·FFprobe 길이 검증, 다운로드/렌더 취소 처리.
- 확인 완료 범위: 오프라인 가짜 yt-dlp 가져오기·캐시 재사용 테스트, 기존 FFmpeg 3클립 합성 테스트, CI 타입/린트/빌드.
- 미확인 범위: 실제 YouTube 사이트 응답으로 테스트 다운로드, Mac/Windows 앱 설치상태, 서비스 약관 검토, 결과 영상의 원본 내용 일치 및 재게시 권한.

**결론:** 개인 사용자 목적을 위해 링크→MP4 경로를 구현하지만, 범용 영상 접근 보장 또는 자동 재게시 권리를 주장하지 않는다.
