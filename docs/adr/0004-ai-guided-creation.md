# ADR-0004: AI Guided Creation을 ShortFab 기본 제작 흐름으로 채택

- 날짜: 2026-10-22
- 상태: Accepted (제품 UX 방향 결정, 구현은 진행 전)
- 영향: 제품 기획/UX/로드맵/아키텍처/AGENTS/README

## 배경

기존 ShortFab은 URL 탐색, IN/OUT, 중앙 9:16 프리뷰, 타임라인과 출력 패널이 항상 보이는 수동 영상 편집기 구조였다. 핵심 기술(공개 YouTube URL→개인용 MP4 출력)은 실기 성공했지만 실제 사용자 의도는 **URL→AI 클립 추천→화면 자동 배치→자막→사운드→CTA→검토/출력**으로, **AI의 초안을 단계별로 확인하고 조금씩 수정하는 과정**이다.

## 결정

기본 UI를 8단계 AI Guided Wizard로 전환한다. 매 단계 AI 제안·미리보기·부분 수정·재생성·승인을 제공하며 승인/수동 잠금값을 유지한다. 전문 타임라인은 Advanced Edit에 둔다. AI 추천과 자동 레이아웃을 Phase 3에서 핵심 AG2/AG3으로 앞당긴다. 출시는 추천·화면 합성/자막/오디오/CTA/최종 결과가 실제 구현되고 검증된 범위로 제한한다.

## 고려한 대안

- 수동 3열 편집기를 계속 기본으로 유지: 사용자가 편집 작업을 많이 해야 하므로 기각.
- 원클릭 완전 자동 완성 후 결과 편집: 빠르지만 사용자가 과정별로 교정할 통제권이 약해 기본 UX로는 기각. 후속 선택형 모드 가능.
- 기존 화면 상단에 스텝바만 추가: 실제 자동 생성·승인 흐름이 없으므로 기각.

## 결과

신규 StepRecord 상태 머신, AI 초안/수동 수정 분리, 다운스트림 invalidation, 합성 프리뷰, old-project 마이그레이션 필요. 기존 실기 성공/기술 및 권리 경계는 유지. 기준은 [기획](../PRODUCT_BLUEPRINT.md), [UX](../UX_WORKFLOWS.md), [로드맵](../ROADMAP.md), [아키텍처](../ARCHITECTURE.md)이다.
