# ShortFab UX v2.0 — AI Guided Wizard

> 2026-10-22 승인된 **목표 UX**. AG1에서 별도 8단계 Wizard 셸·기본 URL 입력·승인/이전/건너뛰기와 Advanced Edit 분리 **코드 반영**. AG2 전사 기반 클립 추천과 AG3 화면/자막 스타일 갤러리 코드가 추가됐지만 TTS/CTA·렌더 동등 재생 프리뷰·실제 E2E는 아직 목표 UX이며 [현행 구현 상태](IMPLEMENTATION_STATUS.md)에서 구분한다.

## 제품의 핵심

기본 화면은 영상 편집기가 아니라 **AI 제작 마법사**다. **AI가 먼저 만들고 → 사용자가 조금 손보고 → 승인하면 → 다음 단계로** 넘어간다. 'Quick Create'는 더 이상 수동 탐색·편집기의 단축 경로가 아니다.

## 공통 화면

- 홈: **YouTube URL** 큰 입력창, 선택형 '어떤 쇼츠를 원하나요?' 입력, '쇼츠 만들기', 최근 프로젝트.
- 제작: 상단 **원본 / 클립 / 스타일 / 나레이션 / 자막 확인 / CTA / 검토 / 출력** 진행바, 현재 단계만 표시하는 추천 카드, 계속 보이는 9:16 미리보기, 이전·'이대로 사용하고 다음' 버튼.
- 각 단계 공통: **그대로 사용 · 조금 수정 · 다시 생성**. 필요한 단계는 건너뛰기(OFF) 지원. 고급 편집은 접힌 별도 진입.
- 작은 창: 미리보기와 현재 단계가 우선, 패널/세부 설정만 스크롤. 재생 시간, 출력과의 프리뷰 차이, AI 작업 상태를 명확히 표시.

## 단계별 상세 UX

| 단계 | 처음 보이는 것 | 허용되는 소폭 수정 | 완료 조건 |
|---|---|---|---|
| 01 원본 | URL·영상 제목/길이·분석/렌더 가능 상태·분석 진행 | 원하는 주제·길이·언어, 소스 재시도 | 접근 가능한 소스 확인·분석 시작 |
| 02 클립 | 5~10개 후보 카드: 시간·길이·제목·대사·추천 이유·재생 | 앞뒤 조금 자르기/늘리기, 대본 문장 선택, '더 웃긴 장면' 재추천 | 하나 이상 후보 승인 |
| 03 스타일 | 실제 클립 프레임+예시 자막이 함께 있는 통합 스타일 카드 | 스타일 선택·초점 슬라이더 | 프레임+자막을 동시에 결정 |
| 04 나레이션 | 원본 음성 유지/OFF 또는 시스템 TTS 원고 | 원고와 보이스 언어, ON/OFF | 음성의 자막 출처 확정 |
| 05 자막 확인 | 나레이션 ON이면 원고 문장별 자막, OFF면 원본 전사 기반 자막 | 나레이션 원고 재수정 또는 원본 문장·타이밍 교정 | 실제 같은 문장을 MP4 자막으로 출력 |
| 06 CTA | OFF/오버레이/엔드카드·추천 문구 | 문구·지속 시간·위치 | OFF 또는 CTA 승인 |
| 07 검토 | 지금까지 선택한 모든 구성의 최종 프리뷰와 QC | 잘못된 단계로 돌아가 수정 | 최종 승인된 Composition |
| 08 출력 | MP4 옵션·진행·저장, 게시 문구 초안 | 해상도, 제목·설명·공개 범위 | MP4 출력; 게시는 별도 확인 |

### 01 원본/자동 분석

붙여넣기 후 즉시 URL 검사/미리보기/메타데이터를 보여주고, 전사·장면·클립 추천 진행을 단계별로 알린다. 분석이 오래 걸려도 취소/재시도 및 직접 선택 대안. 영상 임베드만 된 상태와 렌더 가능 상태를 혼동하지 않는다. 원본 미디어/권리/모델 문제를 숨기지 않는다.

### 02 AI 클립 추천

클립마다 **미리보기, 시간 범위, 길이, 요약, 대사 인용, 추천 이유**. 실제 5~10개를 만들 수 없으면 적은 수와 이유를 설명. 추천은 유효한 시간 범위만 반환한다. 선택된 후보 재생/반복 후 **대본 드래그** 또는 간단한 앞뒤 슬라이더로 미세 수정. 전체 타임라인은 고급 모드에서만. 여러 후보를 선택하면 각자의 03~08 상태를 독립 관리한다.

### 03 통합 스타일

화면 배치와 자막을 따로 선택하지 않는다. 실제 선택 클립의 프레임 또는 원본 썸네일 + 대사 예시를 하나의 카드로 넘겨 비교한다. 필요하면 가로 초점을 슬라이더로 조금 수정한다. 선택한 스타일은 FFmpeg 렌더에 반영된다. 인물 추적·자동 분할은 기본 AG3에서 제외한다. 참고용 정지 프레임과 실제 재생형 MP4 프리뷰는 다르며 후자는 후속 구현 과제다.

### 04 나레이션 → 05 자막 확인

원본 음성을 그대로 쓰거나 TTS 원고를 작성해 추가 음성을 선택한다. TTS ON이면 그 원고가 출력 자막 내용이며, 실제 로컬 음성의 문장별 길이로 자막 타이밍을 정한다. OFF면 기존 Whisper 기반으로 문장별 자막을 제안하고 강조·Hook을 교정한다. 텍스트 직접 수정 후 다른 스타일을 골라도 교정은 살아있다. 한국어 폰트, 긴 문장 줄바꿈, 플랫폼 안전 영역, 타임코드 정확성 검사.

### 05 나레이션·사운드

기본 추천은 **원본 보존**. 추가 나레이션이 필요할 때 원고와 샘플 2~3개, 듣기/편집/승인; 적법한 BGM/효과음 라이브러리와 더킹을 활용. AI가 내용 왜곡·무허가 음원을 자동 선택해서는 안 된다. TTS 비용·외부 전송과 라이선스 상태 표시.

### 06 CTA

CTA **없음**을 선택 가능. 팔로우/구독/풀영상/다음 편 목적에 따라 문구/애니메이션/노출 시간 자동 제안. 사용자는 한두 항목만 수정. 엔드카드로 늘어난 전체 영상 길이와 클릭 불가능한 영상 텍스트 고지.

### 07 최종 검토

실제 출력과 동등한 프리뷰, 구간·배치·자막·소리·CTA의 요약 및 상태표. 안전 영역, 검은 장면, 말소리 싱크, 음량 피크, 길이·구성 버전 확인. 수정이 필요하면 해당 단계로 이동; 다른 승인값은 보존.

### 08 익스포트/게시

승인된 스냅샷으로 FFmpeg MP4 출력. 기존 렌더 결과는 데이터 변경 시 '이전 버전' 처리. SNS 업로드는 권한·계정·권리 조건이 성립할 때만 버튼 활성화하고 별도 사용자 최종 승인 후 시작. Google 업로드 완료와 YouTube 처리 완료를 구분한다.

## 단계 상태와 오류 정책

- 상태: **not_started / generating / proposed / accepted / needs_review / failed / skipped**.
- 공통: 이전→승인·수정 유지, 다음→유효성 검사/자동 저장, 다시 생성→해당 AI 소유 필드만 갱신, 오류→최종 승인된 값 유지+재시도.
- 사용자가 고친 필드는 잠금/오버라이드로 기록. 교체를 원할 때만 충돌 확인.
- 클립 IN/OUT 변경 시 화면/자막/소리/CTA/검토를 필요 범위만 재검토. 자막 스타일만 변경했을 때 원본 클립 추천은 보존.
- 프로젝트 재열기에서 현재 단계, 클립별 진행도, 생성 중 취소/재시도 상태를 보존한다. 다른 클립 변경사항을 침범하지 않는다.

## 고급 편집

현재 수동 YouTube seek/IN·OUT, 반복, 자막 타임코드, 로컬/허가 원본·익스포트·YouTube 게시 도구는 없애지 않는다. **고급 편집** 버튼으로 접근하며 동일한 데이터 모델을 편집한다. 다시 AI 제작 모드로 돌아오면 관련 단계만 needs_review로 표시한다.

## 실제 수용 시험

- 편집 경험 없는 사용자가 URL 입력 후 타임라인 없이 첫 후보 선택·8단계·MP4 완료.
- 뒤로가기/재생성/강제 종료·재열기/다중 클립 간 승인값 보존.
- 실패/무음/접근 제한/모델 미설치에서 가짜 AI 결과 없이 대안 안내.
- 최소 1280×860 및 작은 Electron 창에서 프리뷰/승인 버튼 항상 접근 가능.
- 화면의 'AI가 만들었다' 설명은 실제 생성기가 연결된 경우에만 노출한다.


## AG1 1차 실제 화면 동작과 차이 (2026-10-22)

현재 dev는 `단계별 제작`을 기본으로, `고급 편집`에서 기존 3열 수동 작업 영역으로 전환한다. 8단계 상단 바의 접근은 이전 단계의 승인/건너뛰기 상태로 보호된다. Source는 YouTube URL/길이, Clip은 **현재 플레이헤드에서 수동으로 30초 후보 생성**, 화면은 중앙 크롭/해상도, 자막은 기존 Whisper 호출, 소리는 원본 유지, CTA는 OFF, 검토는 현재 적용된 값 표, 출력은 기존 FFmpeg 경로다. 새 AI 후보/추천 카드·재생성은 아직 비활성화 상태이고 생성된 척하지 않는다. 앱 오른쪽 참고용 YouTube IFrame을 출력과 동일한 프리뷰로 표시하지 않는다.

**AG1 실기 수용 필요:** Mac/Windows에서 URL→마법사 8단계→MP4, 강제 종료/재열기/클립별 재검토와 고급 편집 전환 확인. `docs/ROADMAP.md`에서 exit 체크 전 실제 사용 기록을 남길 것.


## AG2 실제 추천기 UX와 목표 비교 (2026-10-22)

02 클립의 **AI 음성 분석 · 클립 자동 추천**에서 로컬 모델·언어·진행률/취소/오류 및 수동 대안을 제공한다. 성공하면 실제 대사/추천 이유/시간/길이 카드가 최대 8개 등장하며, 각 후보는 오른쪽 YouTube 원본 플레이어에서 해당 구간을 재생할 수 있다. 체크박스로 여러 개를 클립에 추가하고 숫자 또는 실제 문장 기준으로 IN/OUT을 수정한다. '더 짧게'와 '더 역동적으로'는 전사 캐시에서 새 후보를 찾으며 기존 승인값을 덮어쓰지 않는다. 전사 실패 또는 무음이라면 구간 선택 버튼을 계속 사용할 수 있다.

현재 UI의 'AI'는 **Whisper 음성 인식 + 결정적 휴리스틱**을 뜻한다. 클립 자막 교정/문장 드래그 선택, 사용자의 자연어 취향 조건, 영상 장면·화자 인식 및 외부 LLM 후보 추천은 아직 목표 기능이다. **유효한 대사가 부족하면 5~10개를 채우려고 허구의 후보를 반환하지 않는다.**


## 2026-10-22 결정: 자동 배치보다 스타일 카드 갤러리 우선

사용자가 요구한 기본 UX는 `03 화면 → 04 자막 → 05 소리 → 06 CTA` 각 단계에서 **여러 시안을 좌우로 슬라이드 → 같은 영상에 스타일 미리보기 → 마음에 드는 것을 탭 → 몇 가지만 수정 → 승인**하는 흐름이다. AI가 사용자의 의도 없이 단일 레이아웃을 확정하지 않는다. 갤러리 항목은 실제 합성 엔진과 연결된 선언형 스타일 ID/버전/지원 기능을 가져야 하며, 예시만 그리는 카드는 출시 불가.

현재 dev의 첫 구현: 화면 카드 4종(중앙/왼쪽/오른쪽/흐린 배경 전체 보기)과 자막 카드 4종. 원본 YouTube 썸네일은 **영상별 참고 장면**이며, 사용자가 요청하면 진짜 선택 클립의 **정지 프레임**을 FFmpeg로 추출해 카드 이미지로 사용한다. 카드의 CSS 구도는 실제 FFmpeg 필터를 시각적으로 근사한다. **최종 동등 동영상 프리뷰는 아직 없음**을 명시하고 8단계 검토에서도 이를 오인시키지 않는다. 카드 선택/수동 크롭/수동 자막을 재생성이나 단계 왕복 시 보존한다.

후속 AG4~AG6에서도 자막/나레이션/CTA에 같은 갤러리(기본 몇 종→트렌드 신규 스타일 추가, 버전 검증, 비용/저작권/접근성 고지)를 적용할 계획이다. AI는 필요할 경우 갤러리 정렬을 돕되 **최종 스타일 결정은 사용자**에게 둔다.


## AG4 실제 코드 추가 · 2026-10-22

04 자막에서 8종 카드를 넘겨 고르고, AG2 실제 음성 분석 캐시의 문장과 타임코드를 클립 상대 자막으로 직접 변환한다. 캐시가 없다면 Whisper 클립 전사 기능도 유지한다. 사용자는 Wizard를 벗어나지 않고 문장·IN/OUT·강조 체크/삭제/추가, 상단 Hook OFF/ON·문구·시간·디자인을 직접 수정/승인한다. Hook 추천은 실제 인식 텍스트에서 질문/강조 표현을 그대로 가져오며 외부 창작 AI 문구가 아님을 명시한다. 카드 정지 시안과 실제 FFmpeg 동영상은 구분한다. [상세](AG4_CAPTIONS.md).
